# Tic-Tac-Toe-Game
<h3> A simple, web-based Tic-Tac-Toe game.</h3>
<p><b>HTML:</b> For the structure of the game (buttons, messages, and title).

<b>CSS:</b> For styling the game board, buttons, and overall layout.

<b>JavaScript:</b> For the game's logic, including handling turns, checking for a winner, and resetting the game.</p>
